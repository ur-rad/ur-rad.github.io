title: "Adventures in Reproducing and Integrating Open-Source: Developing Guidelines for Modular Software Components in Robot Grasping and Manipulation Pipelines for Picking In Clutter"
abstract: "When developing a novel software component of a robot system, researchers typically integrate open-source code for other components in the pipeline, such as perception, grasp planning, and motion planning. However, there are several bottlenecks related to the accessibility and reproducibility of open-source which are stifling research, development, evaluation, and deployment of robots. To this end, we are working to develop community-driven guidelines for modular components in robot software pipelines in the context of picking in clutter. In this work, we investigate reproducing and integrating multiple perception and grasp planning components used in vision-based perception-to-action pipelines. The architecture and methodology used to conduct these exercises are reviewed, highlighting issues encountered along the way. Recommendations for guidelines to improve accessibility, reproducibility, and integration of modular open-source components are shared related to the assets included in an open-source release, methods to modularize components, and practices for development and testing."
