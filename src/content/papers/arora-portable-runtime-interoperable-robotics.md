title: "Arora: a Portable Runtime for Interoperable Robotics Applications"
abstract: "Robot software is heterogeneous: functionality arrives as components that must each be integrated, the middleware beneath them is plural, and an integrator working across robots writes an adaptation layer once per platform. Robotics developers and users ask for a higher level of abstraction, for software decoupled from hardware, and for reusable components behind standardized interfaces. We present Arora, an open-source device runtime that answers those needs in one place. An Arora device is one process around one data store, which hardware, external clients, behavior and computation reach through four interfaces. Capabilities, including control policies and animation, are WebAssembly modules built once, and running anywhere, including in a browser. This should ease the writing and testing of behaviors away from the physical robot and its middleware. Behaviors are written as either behavior trees or dataflow graphs, on top of lower-level interfaces that are agnostic from other middleware. We close on Vizij, an earlier attempt to standardize interactive behaviors through face rigging, and on the points where Arora converges with it."
